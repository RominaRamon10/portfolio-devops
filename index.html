Lo que construí

Software de Gestión Aduanera

Proyecto integrador final de la carrera: sistema web para la gestión de operaciones aduaneras, desarrollado en conjunto con otra estudiante y junto a un cliente real, un despachante de aduana. Frontend en React conectado mediante una API REST a un backend en C# con base de datos SQL, desplegado en Azure (Web Services y Blob Storage) con integración y despliegue continuo.

React C# SQL Azure CI/CD
Rofux — E-commerce ↗ ver repo

Single Page Application de e-commerce de ropa, desarrollada de forma individual como proyecto final del curso de React. Permite explorar el catálogo, filtrar por categorías, ver el detalle de cada producto, gestionar el carrito y finalizar la compra. Las órdenes se almacenan en Firebase Firestore.

React JavaScript Firebase
Portfolio DevOps ↗ ver repo

Este mismo portfolio, construido a lo largo del Certificado DevOps de ORT: versionado con Git, dockerizado con nginx, publicado en GitHub Pages con deploy automático mediante GitHub Actions y con análisis de calidad en SonarCloud.

Docker GitHub Actions SonarCloud
